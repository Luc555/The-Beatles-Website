# Beatles Fanpage 🎸🎶  

Bem-vindo ao **Beatles Fanpage**! Este site foi criado para celebrar uma das bandas mais icônicas da história da música. Aqui, você encontrará informações sobre os integrantes, álbuns, curiosidades e os desenvolvedores do projeto.  

## 🚀 Sobre o projeto  
Este projeto foi desenvolvido como parte de um trabalho acadêmico utilizando **HTML, CSS e JavaScript**, com o objetivo de ser hospedado diretamente no **GitHub Pages**.  

## 📌 Estrutura do site  
O site conta com as seguintes páginas e funcionalidades:  

- **Home**: Exibe uma imagem dos quatro integrantes da banda, seus nomes e um botão "Saiba Mais", que direciona para a página "Integrantes da Banda".  
- **Integrantes da Banda**: Apresenta uma breve descrição de cada integrante dos Beatles.  
- **Álbuns**: Lista os álbuns da banda, incluindo nome, data de lançamento e imagem.  
  - **Clique no nome** do álbum para abrir sua página no Spotify.  
  - **Clique na imagem** para assistir ao álbum no YouTube.  
- **Curiosidades**: Um espaço com mais de 50 fatos interessantes sobre a banda.  
- **Sobre**: Informações sobre os desenvolvedores do site e o propósito do projeto.
